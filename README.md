# 🍝 Creamy Garlic Pasta — Recipe Card

A professional and responsive recipe card webpage developed for the
Veda Technology Web Development Internship — Task 11.

## 📌 Internship Task

- **Company:** Veda Technology
- **Track:** Web Development
- **Task:** Task 11 — Recipe Card Page
- **Level:** 1
- **Technologies:** HTML5 + CSS3

## 🎯 Objective

Build a single recipe card that presents:

- Recipe image
- Recipe title
- Ingredients
- Preparation steps
- Cooking information
- Responsive mobile and desktop layouts

## ✨ Features

- Professional recipe card UI
- Responsive mobile design
- Responsive tablet design
- Responsive desktop design
- Semantic HTML5 structure
- Local recipe image
- `<figure>` and `<figcaption>` for the recipe image
- `<ul>` for ingredients
- `<ol>` for preparation steps
- Consistent spacing and typography
- Accessible image alt text
- CSS variables for maintainable styling
- No JavaScript required

## 🛠️ Technologies

- HTML5
- CSS3
